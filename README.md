# Audio-FSK-Modem

基于C语言的音频2-FSK调制解调仿真，包含Goertzel解调、前导码同步与误码率(BER)计算。

##  功能特性
* 生成16-bit PCM WAV音频信号（数字0 -> 1200Hz，数字1 -> 2200Hz）
* 加入32-bit前导码用于接收端时间同步
* 使用 Goertzel 算法进行频点能量检测与解调
* 计算误码率（BER），目前在无噪声理想信道下 BER = 0.000000

##  如何编译与运行
```bash
# 编译发射端
gcc tx.c -o tx.exe -lm

# 编译接收端
gcc rx.c -o rx.exe -lm

# 生成带有噪声的音频（例如添加 10dB 的信噪比）
./tx.exe test.wav 10

# 接收端解调并计算误码率（与 gold.bits 进行对比）
./rx.exe test.wav gold.bits


在开发过程中，我解决了两个棘手的底层问题：
1. C语言常量取地址报错：在写入WAV文件头时，宏定义的常量无法使用 & 取地址，通过引入局部临时变量分配到栈区内存后解决。
2. Windows隐藏后缀名导致的编译失败：文件后缀被系统隐藏，导致出现 tx.c.c、rx.c.cs 等错误格式。通过开启“文件扩展名”显示并重命名，配合GCC编译器正确处理。

实验数据与结论
   通过多组信噪比（SNR）仿真，测得系统误码率（BER）数据，绘制出关系曲线。
   · 抗噪平坦区（20dB 至 -14dB）：误码率均保持在 0.0000，系统稳定。
   · 悬崖效应区（-16dB 至 -20dB）：误码率从 0.0066 骤增至 0.0388，系统链路失效。
